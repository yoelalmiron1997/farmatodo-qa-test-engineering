# ADR-006 — Reporting desacoplado sobre un esquema versionado

**Estado:** aceptada · **Fecha:** 2026-10-23

## Contexto
Reportes, gate, historial y portal deben poder probarse sin navegador y evolucionar sin romper datos viejos.

## Decisión
Pipeline ejecución → recolección (JSONL por intento) → normalización (`RunResult`, Pydantic, `schema_version: 1`) → validación → persistencia → agregación → visualización. El JSON Schema se exporta desde el modelo (`qa results schema`).

## Alternativas consideradas
Usar el XML de JUnit como fuente (no registra intentos individuales ni categorías) · reportes generados desde los Page Objects (acoplamiento).

## Consecuencias
Una versión 2 del esquema requerirá una función de migración probada.
