# ADR-010 — MkDocs Material en GitHub Pages

**Estado:** aceptada · **Fecha:** 2026-10-23

## Contexto
Los evaluadores deben entender la calidad del proyecto sin ejecutar código, con costo de infraestructura cero.

## Decisión
Portal estático generado en cada despliegue desde specs + historial (`qa portal build`) y publicado con las acciones oficiales de Pages. Diagramas Mermaid; gráficos con Chart.js y tabla equivalente (funciona sin JavaScript).

## Alternativas consideradas
Allure (bueno para ejecución, no integra SDD ni trazabilidad) · backend propio (innecesario).

## Consecuencias
Los datos del portal tienen la antigüedad del último despliegue; cada número indica corrida, fecha y commit.
