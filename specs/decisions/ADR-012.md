# ADR-012 — uv + lockfile para reproducibilidad

**Estado:** aceptada · **Fecha:** 2026-10-23

## Contexto
El entorno local y el de CI deben resolver exactamente las mismas versiones.

## Decisión
`pyproject.toml` con grupos `dev` y `docs`, `uv.lock` versionado y `uv sync --frozen` en CI. Python 3.12 fijado en `.python-version`. Las acciones de GitHub se fijan por SHA de commit, con comentario de versión, y se actualizan con Dependabot.

## Alternativas consideradas
pip + requirements.txt sin lock (no reproducible) · Poetry (equivalente, más lento).

## Consecuencias
Las versiones reales de Python, pytest, Selenium y Chrome se registran en cada resultado.
