# ADR-011 — Historial en una rama `qa-history` con archivos inmutables

**Estado:** aceptada · **Fecha:** 2026-10-23

## Contexto
Los artifacts de Actions expiran y no son consultables desde el portal.

## Decisión
Cada corrida autorizada (solo `master`, nunca PR) agrega `runs/<workflow>/<AAAA>/<MM>/<run_id>-<intento>.json`. La escritura es exclusiva (`O_EXCL`) y serializada (`concurrency: qa-history-writer`), con reintento de push ante carreras. Sin índice versionado: se calcula al construir el portal.

## Alternativas consideradas
GitHub Pages como almacenamiento (se sobrescribe en cada deploy) · base de datos externa (credenciales y costo).

## Consecuencias
Crecimiento estimado 20–60 KB por corrida; retención de 365 días o 500 corridas con compactación mensual documentada.
