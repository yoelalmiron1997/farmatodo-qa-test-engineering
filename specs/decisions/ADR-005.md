# ADR-005 — Oráculo independiente con perfil de reglas y datos P0 inequívocos

**Estado:** aceptada · **Fecha:** 2026-10-23

## Contexto
Los valores esperados no pueden salir de la aplicación, pero las reglas de conteo de WordCounter no están documentadas.

## Decisión
El oráculo es una función pura `(texto, RuleProfile)`. El perfil se fijó a partir de 42 observaciones reales (spike) y el oráculo se prueba contra ellas (TC-FW-009). Los datos P0 producen el mismo resultado con cualquier regla razonable. El oráculo no comparte código con el algoritmo del Ejercicio 4 (contrato de import-linter).

## Alternativas consideradas
Calcular el esperado leyendo la página (tautológico) · reutilizar el algoritmo del Ejercicio 4 (otras reglas: desempate alfabético, puntos de código).

## Consecuencias
Si el sitio cambia sus reglas, falla primero la caracterización TC-WC-015 y el diagnóstico es inmediato.
